# 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기

## "," , ":"을 구분자로 가지는 문자열인 경우

- 구분자를 기준으로 분리한 숫자의 합을 반환한다.

## 커스텀 구분자를 지정할 수 있다.

- "//" "\n"사이에 위치하는 문자를 커스텀 구분자로 사용
- "//;\n1;2;3 1+2+3

## 사용자가 잘못된 값을 입력할 경우 illegalArgument발생 후 종료

### 입력

구분자와 양수로 구성된 문자열

### 츨력

덧셈 결과

```
결과 : 6
```

실행 결과 예시

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
